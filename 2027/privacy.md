IEEE ISMAR 2027 is sponsored by the IEEE Computer Society. Personal data is handled in accordance with the [IEEE Privacy Policy](https://www.ieee.org/security-privacy.html). This notice explains what happens when you visit this website.

## Hosting

This website is hosted on GitHub Pages (GitHub, Inc.). GitHub logs the IP address of visitors for security purposes. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Cookies and analytics

This website does not use analytics or advertising cookies and does not track visitors. The cookie banner stores a single cookie (`cookieconsent_status`) to remember that you dismissed it. The banner script is loaded from IEEE (Amazon Web Services) and cdnjs (Cloudflare), which receive your IP address when delivering these files. Fonts and images are served from this website.

## Registration and other forms

This website does not collect personal data. Conference registration and submission systems will be operated separately and will ask for your explicit consent to the IEEE Privacy Policy and the [IEEE Event Terms and Conditions](https://www.ieee.org/conferences/event-terms-and-conditions.html) before any data is collected.

## Contact

For questions about this website, contact [generalchairs2027@ieeeismar.net](mailto:generalchairs2027@ieeeismar.net). For questions about IEEE’s handling of personal data, see the [IEEE Privacy Policy](https://www.ieee.org/security-privacy.html).
